Copy the app code (index.html)

  1. Tap Copy all code below. Wait for "Copied".
  2. Open GitHub: github.com/sabareshmark-ship-it/Collections-app/edit/main/index.html
  3. Tap inside the editor, select everything (long press, then Select all), and paste.
  4. Tap Commit changes, then Commit changes again.
If the button does not copy: tap inside the box below, long press, tap Select all, then Copy.
